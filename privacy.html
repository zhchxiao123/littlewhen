隐私政策

适用于小当时（Littlewhen）Mac 与 iPhone 应用。开发者：zhchxiao123。生效日期：2026 年 11 月 16 日。版本：v1。

一句话：开发者不运营任何云服务，也不收集你的任何数据。你的记录要么只在你的设备上，要么在你自己选择连接的服务器上。下面按数据所在的位置逐项说明。

1. 开发者收集什么

什么都不收集。应用不包含统计、广告或崩溃上报 SDK，不会把任何内容、标识符或使用情况发给开发者。应用没有内购和订阅，开发者也不会收到任何付款或交易信息。因此在 App Store 的隐私标签中，本应用为「不收集数据」。

2. 只在你设备上的数据

不连接服务器时，全部记录、附件、分类、标签、搜索索引、回想统计与会话都只保存在这台设备的加密资料库（SQLCipher）中，不会上传到任何地方。

3. 系统权限

以下权限都只在你用到对应功能时才请求，拒绝后其他功能照常可用：

  • 相机、照片：拍照或选图作为记录附件；扫码授权保险箱。
  • 麦克风：录音作为记录附件。
  • 位置：只有你打开「新记录附带位置」后，保存新记录时记下当时的位置和地名。位置是那条记录内容的一部分，和记录一起保存、同步和删除，开发者收不到。
  • Face ID：解锁本机的保险箱。验证由系统完成，应用拿不到你的面部数据。

4. 你连接的服务器

多端同步需要连接一台服务器。这台服务器由你自己部署，或者由你信任的人（比如家人、朋友）部署，地址由你在应用里填写；应用不内置任何默认服务器。

连上服务器后，账号信息（用户名、密码的单向摘要、登录会话与设备信息、你选择绑定的恢复邮箱）以及普通记录（不在保险箱里的记录）及其附件会同步到这台服务器。服务器能够读取并处理普通记录，例如同步、生成缩略图、提供搜索与 Agent 接口；这不是端到端加密。服务器上的数据如何保存、备份和删除，由该服务器的管理员负责，开发者无法访问，也不承担其运维责任。

5. 保险箱

放进保险箱的记录，其正文、标签、位置、心情、分类归属、附件、缩略图，以及转写、描述和 OCR 文本，都在你的设备上加密后再同步。服务器只保存密文和同步所需的公开信息。开发者、服务器管理员与任何 Agent 都无法读取保险箱内容。

服务器仍能看到以下元数据：用户与记录 ID、创建/更新相关时间、发生日期的天粒度、密文体积、附件密文哈希与体积、操作序号。例如「某用户在某天有 3 条保险箱记录，密文共 40 MB」仍可能暴露活动频率、时间与规模。

加密只对未来生效：普通记录转入保险箱前的历史备份、已下载副本或导出文件可能仍含明文。口令、24 词恢复短语和所有仍可解锁的设备都不可用时，内容永久不可恢复，没有人能代为解密。

6. AI 回想

回想卡、建议问题与回看统计由本机计算，不依赖模型，内容不出设备。总结、洞察与回答需要模型，应用不自带模型，按你在「设置 › AI 回想」的选择流向不同的地方：

  • 本机模型：内容不出设备。
  • 自带密钥：相关记录的文本发送给你填写的模型服务商，受该服务商的隐私政策约束。
  • 服务器提供：相关记录的文本经你连接的服务器转发给服务器管理员配置的模型服务商。

第一次连接模型服务商、切换到「服务器提供」或打开服务器识别图片和录音、自动归类前，应用会说明内容发给谁，你点「同意」后才会发送。无论哪种来源：保险箱内容永不参与；助手不会自动写入记录。开发者不经手任何 AI 请求。

7. Agent 授权（API 与 MCP）

你可以在服务器上创建 Token，让 Claude、ChatGPT 等外部 Agent 读取（或经你明确允许后写入）已同步的普通记录。Token 可限定只读与分类范围，随时吊销。保险箱内容与未同步的本机内容不会因授权而变得可用。Agent 取走内容后如何处理，由该 Agent 的提供方负责。

8. 导出

你随时可以把全部记录与附件导出为 ZIP（Markdown、完整数据与原始附件）或 PDF。保险箱内容需要单独解锁并确认后才以明文导出，请妥善保管导出文件。

9. 删除

在「设置 › 账号与同步」可以删除你在服务器上的账号：撤销全部登录、Agent 授权与同步设备，服务器随后清理云端记录与附件；服务器备份的保留时间由服务器管理员决定。本机资料库默认保留在你的设备上，删除应用即可一并清除。

10. 未成年人

小当时不面向儿童，也不在知情的情况下收集任何人的数据。你可以用它记录家庭成员（包括孩子）的内容，这些内容是你自己的记录，只在你的设备和你连接的服务器上，受上述规则保护。

11. 你的权利

无论你身处哪个国家或地区（包括欧盟 GDPR、英国、美国加州等法律下的访问、更正、删除、导出和反对处理的权利）：开发者不持有你的任何数据，因此也没有可供查询或删除的副本。设备上的数据由你在应用里直接查看、导出和删除；服务器上的数据请在「设置 › 账号与同步」中导出或删除账号，或联系该服务器的管理员。

12. 变更与联系

政策变更会在本页更新并标注生效日期。联系方式：在 GitHub Issues 新建一条。
