支持

联系

  • 问题、建议与求助：在 GitHub Issues 新建一条。请不要贴出密码、恢复短语或私密正文。
  • 服务器相关的问题（打不开、登录不了、容量满了）请先联系你的服务器管理员；如果服务器是你自己部署的，看下面的「自建服务器」。

常见问题

记录与同步

不登录能用吗？

可以，而且功能完整。记录先写进这台设备的加密资料库，不登录、没有网络都能记。想在 Mac 与 iPhone 之间同步，需要连上一台你自己的服务器。

Mac 和 iPhone 怎么用同一个记忆库？

两端在「设置 › 账号与同步」填同一个服务器地址、登录同一账号，就会同步普通记录与附件；保险箱密文也同步，但需要在新设备上用口令、恢复短语或由已解锁设备扫码授权后才能解开。

离线写的内容什么时候上传？

连上服务器后自动完成同步。本机副本不等于云端已备份，重要内容请定期导出。

保险箱

忘了保险箱口令怎么办？

用 24 词恢复短语重设口令，或在仍处于解锁状态的另一台设备上扫码授权。口令、恢复短语和所有已解锁设备都不可用时，内容无法恢复，开发者和服务器管理员都无法代为解密。

服务器能看到保险箱里的什么？

只有元数据：记录 ID、时间的天粒度、密文体积、附件密文哈希与体积等。正文、标签、附件、转写都是密文。详见隐私政策。

保险箱内容会被 AI 回想或 Agent 用到吗？

不会。保险箱内容永不参与「问一问」，面板会显示被排除的条数；通过 API 与 MCP 接入的 Agent 也拿不到保险箱内容。

问一问 · AI 回想

为什么只有回想卡，没有总结和洞察？

总结、洞察与回答需要模型，应用不自带。到「设置 › AI 回想」选一个来源：本机模型（Mac 上的 Ollama）、自带密钥（填你自己的 API Key），或服务器提供（你的服务器管理员配置好的模型）。回想卡与建议问题是本机统计，不需要模型。

怎么关掉某一类卡片？

「设置 › AI 回想 › 在“问一问”里显示」下，回想卡、总结卡、洞察卡、建议问题各自独立开关。关掉的就不会生成。

回答会写进我的记录吗？

不会。会话单独保存，不写入记录；助手起草的「记一条提醒」「存为记录」都要你点「保存到记录」才入库。

Agent 授权

怎么让 Claude 或 ChatGPT 读我的记录？

「设置 › Agent 授权」里创建一个 Token，可选只读、可限定分类。MCP 地址是你的服务器地址加 /mcp，请求头填 Authorization: Bearer <你的 Token>。应用内有 Claude Code、Claude Desktop、ChatGPT 的逐步说明。

Token 泄露了怎么办？

在「Agent 授权」里立即吊销，再创建新的。Token 只在创建时显示一次，只粘贴到客户端的请求头或访问令牌栏，不要写进聊天内容。

导出、导入与删除

怎么把全部内容带走？

「设置 › 导出全部」。ZIP 包含 Markdown、完整记录数据与原始附件；PDF 适合打印与分享。保险箱内容需要单独解锁并确认后才会以明文导出。

能从别的应用导入吗？

支持 Day One 的 JSON 导出包、Journey 导出包与 Markdown 目录（请先解压并保留照片的相对位置）。

怎么删除账号？

「设置 › 账号与同步 › 删除云端账号」，删除的是你在这台服务器上的账号和数据。删除前请先导出本机副本；详见隐私政策。

自建服务器

服务端怎么部署？

一个容器或一个二进制即可：RM_BASE_PATH=/littlewhen docker compose up --build -d，配好 HTTPS 后，在应用「设置 › 账号与同步」里填入你的服务器地址。反向代理（Caddy / Nginx / Traefik）、备份与监控的文档随源码提供。

家里人也想用，怎么加账号？

服务器默认关闭公开注册。管理员可以在服务器的管理后台创建账号，或者签发邀请码，让家人在应用里用「使用邀请注册」自己注册。每个账号的资料互相独立。

怎么让服务器提供 AI 模型？

在服务器上配置 RM_AI_PROVIDER、RM_AI_ENDPOINT、RM_AI_MODEL 和 RM_AI_API_KEY，再用管理员接口给需要的账号设置 AI 预算（见源码里的服务端文档）。之后应用里选「服务器提供」即可，不用在每台设备上填 Key。

报告问题时请附上

  • 设备与系统版本、应用版本（设置 › 服务与支持）、服务端版本。
  • 发生了什么、期望是什么、能否复现。
  • 不要附上记录正文、附件、口令、恢复短语或 Token。
